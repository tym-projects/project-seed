# Project Seed Roadmap

## Sprint 1：多模式首頁與基礎路由

- 建立 Project Seed 首頁與產品訊息。
- 建立姐姐、妹妹、家長三種模式路由。
- 建立一致的卡片式頁面與主題色。

## Sprint 2：姐姐國語練習

- 新增姐姐模式的國語練習入口。
- 建立單題注音題目畫面與「我會／我不會」選項。
- 驗證路由與 TypeScript。

## Sprint 3：互動與回饋

- 加入答案選擇、正確性回饋與下一題流程。
- 設計「我不會」時的提示與教學引導。
- 建立題目資料結構，支援更多科目與年級。

## Sprint 4：學習紀錄與家長摘要

- 記錄練習完成狀態與常見困難。
- 在家長模式呈現簡潔的學習摘要。
- 規劃資料隱私與帳號需求。

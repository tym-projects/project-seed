# 2026AST 使用與學習紀錄備份

## 正式使用

- 孩子請使用一般瀏覽模式、固定裝置與固定正式 origin；不要使用無痕／私密模式。
- 不要清除網站資料，也不要在未評估影響前更換瀏覽器、裝置、IP 或 port。

## Learning Record 備份

- 家長可在 `/parent` 的「學習紀錄備份」區塊匯出 JSON 備份，並將檔案保存於受信任的位置。
- 匯入前會完整驗證格式、版本、筆數及每筆 Learning Record；驗證失敗不會寫入任何資料。
- 匯入以 `id` 去重：相同內容略過，衝突內容拒絕；成功時只寫入一次既有 storage key。此功能不備份或修改 ReviewSession。
- 備份檔含學習紀錄資料，請勿公開分享或上傳不受信任的服務。

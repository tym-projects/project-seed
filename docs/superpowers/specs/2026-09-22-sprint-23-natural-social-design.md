### A. 姐姐自然：康軒版六上第 1–2 單元

#### `jiejie-natural-science-1`

- 單元／topic：第 1 單元「天氣變化的主角——水」／水的蒸發
- 題型：基礎概念
- 預計難度：基礎
- 題幹：陽光照射下，地面上的水逐漸變少，這主要是因為水發生了哪一種變化？
- 選項：
  1. 水變成水蒸氣，進入空氣中
  2. 水變成石頭，留在地面上
  3. 水變成泥土，混入地面
  4. 水變成鹽，留在空氣中
- 正解：選項 1，answer index `0`
- Hint：想想水受熱後，是否會以看不見的氣體形式離開水面。
- Explanation：水受到陽光加熱後，部分液態水會變成看不見的水蒸氣，這個過程叫蒸發，所以地面上的水會逐漸減少。
- 答案驗證：蒸發是液態水變成水蒸氣；其他三項不是此情境中的水分變化。
- 範圍檢查：對應第 1 單元水與天氣變化的基本概念；不要求未提供的圖表或實驗數據。
- Human Review：確認「蒸發」及「水蒸氣」用語符合 Human 手上的康軒版課程用語。

#### `jiejie-natural-science-2`

- 單元／topic：第 1 單元「天氣變化的主角——水」／生活中的蒸發
- 題型：情境應用
- 預計難度：基礎至中等
- 題幹：小安把洗好的手帕攤開，放在有陽光又有風的地方。下列哪一個理由最能說明手帕比較容易乾？
- 選項：
  1. 風會把手帕變成另一種布料
  2. 攤開並通風，能讓水較容易蒸發
  3. 陽光會把水變成固體冰塊
  4. 手帕吸收空氣後會自動消失
- 正解：選項 2，answer index `1`
- Hint：手帕變乾，是手帕上的哪一種物質離開了？
- Explanation：手帕上的水吸收熱量後會蒸發；把手帕攤開可增加水和空氣接觸的面積，有風也能帶走靠近表面的水蒸氣，因此較容易乾。
- 答案驗證：選項 2 同時符合水的蒸發與攤開、通風的情境；其他選項不符合水的狀態變化。
- 範圍檢查：以日常觀察應用第 1 單元概念，不宣稱所有風速或溫度下乾燥時間必然相同。
- Human Review：確認題目是否需要補充「其他條件相近」的比較條件；目前題目只問合理原因，不比較精確時間。

#### `jiejie-natural-science-3`

- 單元／topic：第 2 單元「物質溶解與水溶液」／溶質與溶劑
- 題型：基礎概念
- 預計難度：基礎
- 題幹：把砂糖加入水中並攪拌，砂糖均勻分散在水裡。這杯糖水中，哪一個配對正確？
- 選項：
  1. 水是溶質，砂糖是溶劑
  2. 砂糖和水都是容器
  3. 砂糖是溶質，水是溶劑
  4. 砂糖和水都不是溶液中的物質
- 正解：選項 3，answer index `2`
- Hint：想想哪一種物質被另一種物質溶解，以及哪一種物質是主要的溶解媒介。
- Explanation：在糖水中，被水溶解並均勻分散的砂糖是溶質；用來溶解砂糖的水是溶劑。砂糖和水混合後形成糖水，也就是水溶液。
- 答案驗證：選項 3 正確區分溶質、溶劑；其他選項混淆兩者或不是物質角色。
- 範圍檢查：對應第 2 單元水溶液基本概念；不延伸至濃度計算。
- Human Review：確認教材是否以「溶質／溶劑」作為本單元正式詞彙。

#### `jiejie-natural-science-4`

- 單元／topic：第 2 單元「物質溶解與水溶液」／加快溶解的方法
- 題型：情境應用
- 預計難度：中等
- 題幹：兩杯水的溫度和水量相同，各加入一樣多的砂糖。甲杯攪拌，乙杯不攪拌。若要比較哪杯砂糖較快溶解，最合理的預測是什麼？
- 選項：
  1. 乙杯較快，因為不攪拌會讓砂糖自動變熱
  2. 兩杯一定同時溶解，攪拌不會造成任何影響
  3. 甲杯較快，因為攪拌會把砂糖變成另一種物質
  4. 甲杯較快，因為攪拌能增加水和砂糖接觸、混合的機會
- 正解：選項 4，answer index `3`
- Hint：比較兩杯唯一不同的條件，再想攪拌對接觸和混合有什麼作用。
- Explanation：兩杯水的溫度、水量與砂糖量相同，主要差異是有沒有攪拌。攪拌可讓水和砂糖接觸、混合得更充分，因此預期甲杯較快溶解；這是在比較溶解速度，不是說砂糖變成另一種物質。
- 答案驗證：選項 4 符合控制變因後的合理推論；選項 2 否定攪拌影響，選項 1、3 的原因不正確。
- 範圍檢查：使用可由文字理解的簡單實驗條件，不依賴圖片或精確數據。
- Human Review：確認教材對「攪拌影響溶解速度」的表述與課程範圍一致。

### B. 姐姐社會：康軒版六上第 1–2 單元

#### `jiejie-social-studies-1`

- 單元／topic：第 1 單元「臺灣民主政治的發展」／總統直接民選
- 題型：基礎概念
- 預計難度：基礎至中等
- 題幹：下列哪一項是臺灣民主政治發展中的可查證歷史事實？
- 選項：
  1. 1996 年臺灣舉行第一次總統直接民選
  2. 1996 年臺灣取消所有公共選舉
  3. 1996 年臺灣由抽籤決定總統
  4. 1996 年臺灣禁止人民參與投票
- 正解：選項 1，answer index `0`
- Hint：想想「直接民選」代表人民以什麼方式選出總統。
- Explanation：官方總統府資料記載，臺灣在 1996 年 3 月 23 日舉行第一次總統直接民選，這是民主政治發展的重要里程碑。其他選項與此歷史事實相反。
- 答案驗證：選項 1 可由總統府公開資料核對；選項 2–4 均與該史實不符。
- 範圍檢查：使用單一可驗證制度史實，不要求學生支持政黨、政治人物或政治立場。
- 事實來源：總統府[「總統直選 30 週年」說明](https://www.president.gov.tw/News/40029)及歷史資料頁；正式加入題庫前仍需 Human 依教材確認用語與年代呈現方式。
- 實際核對結果：2026-09-22 開啟該官方頁面，頁面明載「1996 年臺灣透過一人一票」完成歷史性的第一次總統直選，並以 `1996.03.23` 作為相關特展主題日期；因此本題的事件與日期表述通過來源核對，未發現需要改寫正解的衝突。

  2. 透過討論與合乎規則的參與形成共同決定

- 答案驗證：選項 2 完整符合題幹三個行為；選項 1、3、4 分別否定平等參與、表達權或共同規則。

- Human Review：確認「多數決後尊重結果」是否需補充少數意見與規則保障，避免形成過度簡化的民主概念。

### C. 妹妹自然：南一版三上第 1–2 單元

#### `meimei-natural-science-1`

- 單元／topic：第 1 單元「認識植物」／植物根的功能
- 題型：基礎概念
- 預計難度：基礎
- 題幹：觀察一株完整的植物，根通常最主要的功能是什麼？
- 選項：
  1. 固定植物，並幫助植物吸收水分
  2. 把陽光變成聲音
  3. 讓植物可以在空中飛行
  4. 把土壤全部變成水
- 正解：選項 1，answer index `0`
- Hint：想想根長在土裡，植物需要從土壤取得什麼。
- Explanation：根通常長在土壤中，可以幫助植物固定，也能吸收水分；植物的不同構造各有功能。其他選項不是根的功能。
- 答案驗證：選項 1 同時符合根的固定與吸收水分功能；選項 2、3、4 不符合植物構造的基本觀察。
- 範圍檢查：對應「認識植物」的基本構造觀察，不要求高年級的光合作用或細胞知識。
- Human Review：確認南一版三上使用「吸收水分」的表述，以及是否需加入「礦物質」等教材詞彙；目前刻意維持低年級用語。

#### `meimei-natural-science-2`

- 單元／topic：第 1 單元「認識植物」／植物與陽光
- 題型：情境應用
- 預計難度：基礎
- 題幹：把兩盆相同的幼苗分別放在窗邊和完全沒有光線的櫃子裡。幾天後觀察，哪一項說法最合理？
- 選項：
  1. 植物完全不需要光線也能一直健康生長
  2. 植物需要適當的光線才能正常生長
  3. 只要沒有水，植物會長得更好
  4. 植物只要放進櫃子就會變成動物
- 正解：選項 2，answer index `1`
- Hint：比較兩盆植物獲得的光線條件，以及植物生長需要的基本條件。
- Explanation：植物生長需要適當的光線、水分與其他條件。窗邊幼苗有機會獲得光線；完全沒有光線的幼苗較難正常生長，因此選項 2 最合理。題目沒有要求預測固定的高度或天數。
- 答案驗證：選項 2 是在給定條件下的合理基本推論；選項 1、3、4 與植物生長常識不符。
- 範圍檢查：以觀察與比較生活情境呈現，不要求使用「光合作用」等尚未確認的高年級術語。
- Human Review：確認題目是否需明確寫出兩盆水分、土壤與植物品種相同，避免把光線以外的變因混入比較。

#### `meimei-natural-science-3`

- 單元／topic：第 2 單元「空氣和水」／空氣占有空間
- 題型：基礎概念
- 預計難度：基礎
- 題幹：把乾紙巾塞在杯底，讓杯口朝下、杯子保持不傾斜，再慢慢壓入水中，最後把杯子直直拿出來。若紙巾仍是乾的，最合理的解釋是什麼？
- 選項：
  1. 紙巾會把所有的水變成空氣
  2. 水只會進入透明的杯子，不會進入紙巾
  3. 杯子裡的空氣占有空間，水沒有直接進入紙巾所在的位置
  4. 紙巾遇到水會自動變成塑膠
- 正解：選項 3，answer index `2`
- Hint：杯子看起來是空的嗎？想想杯子裡原本有什麼。
- Explanation：杯子裡原本有空氣。當杯口向下且沒有讓空氣離開時，空氣占著杯內的空間，水就不容易進入紙巾所在的位置，所以紙巾可以保持乾燥。
- 答案驗證：選項 3 能解釋杯內空氣與水不能同時占用同一空間的觀察；其他選項不是合理的物質變化。
- 範圍檢查：以文字描述簡單觀察活動，不需要圖片；不延伸到壓力或氣體定律。
- Human Review：確認南一版三上實驗器材與操作說明是否相同；若教材操作不同，應改寫情境但保留空氣占有空間的概念。

- 題型：情境應用
- 預計難度：基礎

- 選項：
  1. 刷牙全程讓水龍頭一直流
  2. 為了節水，把用過的水倒進飲水機
  3. 把水龍頭開到最大，讓水更快流完
  4. 刷牙時先關緊水龍頭，需要漱口時再打開
- 正解：選項 4，answer index `3`
- Hint：想想刷牙過程中，什麼時候真的需要用到流動的水。
- Explanation：刷牙時不需要一直使用流動的水，先關緊水龍頭，漱口時再打開，可以減少不必要的用水。其他做法會浪費水或造成不安全的使用。
- 答案驗證：選項 4 是安全、直接且可執行的節水方法；選項 1、3 增加浪費，選項 2 不適合飲水設備。
- 範圍檢查：把水的生活應用連結到節約用水，不要求計算用水量或未提供的統計數字。
- Human Review：確認題目是否符合南一版三上第 2 單元的生活應用範圍。

### D. 妹妹社會：康軒版三上第 1–2 單元

#### `meimei-social-studies-1`

- 單元／topic：第 1 單元「家庭與我」／家庭成員分工合作
- 題型：基礎概念
- 預計難度：基礎
- 題幹：下列哪一個說法最符合家庭生活中的分工合作？
- 選項：
  1. 家庭成員可以依能力和需要一起分擔生活中的工作
  2. 家事只能由一個人永遠負責
  3. 年紀小的人不能做任何家庭工作
  4. 只有賺錢的人才算對家庭有貢獻
- 正解：選項 1，answer index `0`
- Hint：想想家庭成員如何互相幫忙，讓生活更順利。
- Explanation：家庭成員可以依年齡、能力與當時需要，分擔整理、準備物品或照顧等工作。不同成員的貢獻不只一種形式，選項 1 最完整。
- 答案驗證：選項 1 表達合作與多元貢獻；選項 2–4 都把家庭責任錯誤地限制給特定一人或一種貢獻。
- 範圍檢查：符合家庭與我的基本生活概念，不假定家庭一定採用單一角色分工。
- Human Review：確認用語能涵蓋不同家庭型態，避免讓孩子感覺只有某種家庭才是正確家庭。

#### `meimei-social-studies-2`

- 單元／topic：第 1 單元「家庭與我」／家庭溝通
- 題型：情境應用
- 預計難度：基礎
- 題幹：週末姐姐和弟弟都想使用客廳，但時間重疊了。下列哪一種做法最適合解決問題？
- 選項：
  1. 不告訴任何人，直接把別人的物品藏起來
  2. 先說明自己的需要，再和家人一起討論使用時間
  3. 誰先大聲喊叫，誰就可以使用全部時間
  4. 以後都不和家人溝通
- 正解：選項 2，answer index `1`
- Hint：解決家庭中的不同需要時，可以用什麼方式讓大家都被聽見？
- Explanation：家庭成員有不同需要時，可以先清楚說明，再互相聆聽、討論時間安排，找出大家較能接受的方式。選項 2 能保留溝通與合作，其他做法會傷害信任或無法解決問題。
- 答案驗證：選項 2 同時包含表達、聆聽與協商；選項 1、3、4 都避開或破壞溝通。
- 範圍檢查：以家庭日常情境考查溝通，不要求學生透露自己的家庭隱私。
- Human Review：確認題目情境與三年級學生生活經驗相近，並確認「姐姐／弟弟」不造成固定性別或排行角色暗示。

#### `meimei-social-studies-3`

- 單元／topic：第 2 單元「學習和成長」／學習來源
- 題型：基礎概念
- 預計難度：基礎
- 題幹：下列哪一項最能說明「學習和成長」？
- 選項：
  1. 只有考試得到滿分才算學習
  2. 只要年紀變大，就會自動學會所有事情
  3. 我們可以在學校、家庭和生活經驗中學會新的知識與做法
  4. 學習只發生在課本裡，生活中不會學到東西
- 正解：選項 3，answer index `2`
- Hint：想想除了課堂之外，還有哪些地方會讓你學會新的事情。
- Explanation：學習可以發生在學校、家庭和日常生活中，也可能透過練習、觀察和請教別人逐步進步。考試分數只是其中一種結果，不是學習的全部。
- 答案驗證：選項 3 包含多種合理學習來源；選項 1、2、4 對學習做了不正確的單一限制。
- 範圍檢查：符合學習和成長的生活化概念，不引入能力評分或固定成長標準。
- Human Review：確認「學習」與「成長」的詞義是否需依康軒版單元用語調整。

#### `meimei-social-studies-4`

- 單元／topic：第 2 單元「學習和成長」／面對學習困難
- 題型：情境應用
- 預計難度：基礎
- 題幹：小華練習寫字時，發現有幾個字一直寫不好。下列哪一種做法最能幫助他學習和進步？
- 選項：
  1. 因為一次寫不好，就永遠不再練習
  2. 把作業藏起來，假裝自己已經學會
  3. 只看別人寫，自己完全不動筆
  4. 請教老師或家人，找出問題後再分段練習
- 正解：選項 4，answer index `3`
- Hint：遇到不會的事情時，可以先找出困難，再用什麼方式逐步練習？
- Explanation：學習遇到困難時，可以請教可信任的大人或老師，找出需要改進的地方，再把任務分成小步驟練習。選項 4 有助於真正學會；其他做法沒有處理困難。
- 答案驗證：選項 4 同時包含求助、找原因與練習；選項 1–3 都不能形成有效的學習行動。
- 範圍檢查：以三年級日常學習情境呈現，不做能力高低排名，也不建立新的 mastery score。
- Human Review：確認情境和「學習和成長」單元內容一致，並確認解釋語氣不將求助描述成能力不足。

## 4. 題目整體品質檢查

- 16 題均為四選一，answer index 分布為 `0`、`1`、`2`、`3` 各 4 題；正式題庫測試仍應以完整內容驗證答案，不能只依答案位置判定。
- 每題只有一個符合題幹的選項；其餘選項是概念錯誤、條件不符或不適當做法。
- Hint 只提示觀察方向、比較條件或解題概念，不直接重述正確選項。
- Explanation 逐題說明判斷依據；自然題不虛構實驗數據，社會題不加入政黨、人物優劣或族群刻板印象。
- 每題只對應一個 learning unit，不使用未提供圖片即可作答的必要條件。
- 內容是原創練習題，不宣稱為康軒或南一原題，也不宣稱已完成出版社教材審核。

姐姐社會第 1 題的「1996 年第一次總統直接民選」以總統府公開資料核對；正式內容審核仍應依 Human 提供的康軒版課本／教師指引確認課程呈現方式。其他題目主要採單元基本概念與生活情境，正式加入前仍需逐題對照教材內文。
